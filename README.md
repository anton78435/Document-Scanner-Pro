# 📄 Document Scanner Pro — автообрезка и коррекция перспективы за секунды

> «Сфоткал, отсканировал, обрезал — готово!»

**Document Scanner Pro** — это набор утилит для автоматического обнаружения границ документа на фотографии, обрезки и выпрямления перспективы.  
Идеально для оцифровки чеков, визиток, заметок, книг — всего, что можно сфотографировать.

## 🚀 Особенности
- 🧠 Автоматическое обнаружение четырёх углов документа на любом фоне (алгоритм контуров + аппроксимация).
- 🔄 Исправление перспективы (преобразование гомографии) — получается ровный прямоугольник.
- 📷 Поддержка форматов: JPG, PNG, BMP, TIFF (все, что читает ваша библиотека).
- ⚙️ Настройка: можно задать минимальную площадь контура, чувствительность Canny.
- 📁 Пакетная обработка — передайте папку с изображениями, и всё будет обработано.
- 🖥️ CLI с цветным выводом и прогресс-баром (где поддерживается).

## 🛠️ Установка и запуск

В каждой папке с языком — инструкции по установке зависимостей.

| Язык       | Библиотека(и)                 | Команда запуска                         |
|------------|-------------------------------|-----------------------------------------|
| Python     | OpenCV, NumPy                 | `python document_scanner.py <image>`    |
| Go         | gocv                          | `go run document_scanner.go <image>`    |
| Java       | OpenCV (JavaCV)               | `javac -cp .:opencv.jar ... && java ...`|
| C#         | OpenCVSharp                   | `dotnet run`                            |
| Rust       | opencv-rust  или image-rs     | `cargo run -- <image>`                  |
| Ruby       | rmagick + opencv?             | `ruby document_scanner.rb <image>`      |
| PHP        | Imagick (или exec)            | `php document_scanner.php <image>`      |
| JavaScript | Node.js + opencv4nodejs       | `node document_scanner.js <image>`      |

> Для единообразия все скрипты принимают путь к изображению как аргумент.
